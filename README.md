## About

A lightweight, two-player Tic-Tac-Toe game built entirely in C for the command line. This is my first programming project, created to put foundational programming concepts into practice. 

**Features:**
* **Two-Player Mode:** Play locally against a friend taking turns.
* **Input Validation:** Prevents players from overwriting existing moves or crashing the game with invalid characters.
* **Dynamic Win Checking:** Automatically scans rows, columns, and diagonals to declare a winner or a draw.

Built and tested using the GCC compiler (MinGW).
